# Reglas del Asistente para J.A.R.V.I.S.

## Flujo de Trabajo y Commits
- Cada vez que termines una tarea o implementes un cambio solicitado por el usuario, debes realizar un `git add .`, un `git commit` descriptivo y un `git push origin main` al repositorio remoto de GitHub de forma inmediata, asegurando que todos los progresos queden respaldados.

- Manuel no vuelve a tocar Obsidian manualmente.
